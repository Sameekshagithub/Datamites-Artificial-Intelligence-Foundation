# DATAMITES – ARTIFICIAL INTELLIGENCE FOUNDATION

## 📌 Overview

This repository contains my **Artificial Intelligence Foundation** learning materials from **DataMites**. It covers fundamental AI concepts, deep learning, TensorFlow, computer vision, natural language processing (NLP), and AI ethics.

The repository is organized into six modules, with theoretical concepts presented in **PowerPoint (PPT) format** for easy learning, revision, and future reference.
